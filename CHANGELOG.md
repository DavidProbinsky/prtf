# Changelog

All notable changes to PRTF. Versions follow `MAJOR.MINOR`:
a **minor** release adds techniques or improves content; a **major** release changes the structure.
Technique IDs never change between versions.

## v1.1 — 2026-11-24

Interface update. No technique was added, removed or renumbered.

- Clicking a technique now opens its details. Add it to an engagement path with **+** on the card or **Add to path** in the panel.
- **Compact view** shows all 9 tactics on one screen (default on desktop; switch back with *Expanded view*).
- One-line definition for each tactic.
- Shorter intro with About, How to cite and License panels.
- Clearer download buttons, larger small text, brand colors, better contrast in dark mode.

## v1.0 — 2026-11-24

First stable release.

- 108 techniques across 9 tactics: Reconnaissance, Evasion, Lockpicking, Bypass, Wireless & RF, Social Engineering, Implants & Hardware, Exfiltration, Persistence.
- **Permanent technique IDs.** IDs are stored on each technique and never reused. They match the numbering used in v0.x, so existing references still work.
- Released under CC BY 4.0.
- Direct links to single techniques (`/prtf/#PRTF-3.05`) and a *Copy citation* button.
- Machine-readable data in `data/prtf.json` and `data/techniques.csv`.

## v0.3 (beta) — 2026-08-21

- Mobile layout, red team and blue team content for all techniques, engagement path export.
